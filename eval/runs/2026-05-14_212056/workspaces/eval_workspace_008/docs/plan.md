# 測試 Agent 的計畫

- 單元測試（Unit tests）：為 agent 的核心模組撰寫可重複且快速的單元測試，覆蓋推理邏輯、狀態管理與輸入解析。對外部依賴（API、資料庫、感測器）使用 mock 或 stub，以保持測試決定性並快速執行。

- 整合與端到端測試（Integration & E2E）：在受控或模擬環境中驗證 agent 與外部系統的互動，建立代表性情境與回放資料來檢查從輸入到輸出的完整流程。包含故障注入與重試邏輯的檢驗，確保跨組件協調正確。

- 性能、魯棒性與安全測試：衡量延遲、記憶體/CPU 使用與吞吐量，執行壓力測試與長時間運行測試以發現退化或洩漏。進行模糊測試與對抗性測試驗證穩定性與安全性，並定義可量化的指標（SLA、成功率、錯誤率）與告警門檻。
