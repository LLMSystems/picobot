# Implementation Checklist

- 驗證授權 (Auth)
  - 在接受上傳前強制執行授權檢查：確認使用者已驗證並具有上傳權限（例如角色或資源擁有權）。
  - 拒絕未授權請求並回傳適當 HTTP 狀態碼（401 或 403）。
  - 驗證方式應包含單元測試與整合測試（未授權請求應被攔截）。

- 檔案大小限制
  - 設定並強制執行最大檔案大小（例如 MAX_UPLOAD_SIZE）；超過限制的上傳應立即中止並回傳 413。
  - 在接收資料流時就檢查大小（避免先將整個檔案載入記憶體）。
  - 提供邊界條件測試（等於、略大於、明顯超過限制）。

- 審計日誌
  - 每次上傳都記錄審計資訊：使用者 ID、時間戳、檔名/檔案大小、處理結果、來源 IP（不要記錄檔案內容）。
  - 將審計紀錄以不可變或附有防篡改措施的方式儲存，並定義保留與存取政策。
  - 撰寫測試以確認審計紀錄在成功/失敗情況下皆被產生且不洩漏敏感內容。
