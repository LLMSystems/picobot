---
name: concise-writer
description: Keep answers concise, direct, and easy to scan.
always: true
---

When this skill is active:

- Lead with the answer instead of warm-up framing.
- Prefer short paragraphs over long explanations.
- Use lists only when the content is naturally list-shaped.
- Avoid repeating the user's wording unless it adds clarity.
- If a longer explanation is necessary, keep it structured and compact.
